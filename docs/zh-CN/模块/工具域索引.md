#### system 域详细说明

**目录结构**：

```
tools/system/
├── executor.gd                # 调度器
├── atomic_bridge.gd           # 原子工具调用桥，含写保护
├── impl_help.gd               # MCP 能力说明与 Agent 推荐工作流
├── impl_editor.gd             # 编辑器 UI 控制聚合入口
├── impl_runtime.gd            # 运行时控制、统一截图、输入与 step
├── impl_dap.gd                # 高层 DAP 调试协议入口
├── impl_scene.gd              # 场景级工具
├── impl_index.gd              # 索引与搜索工具（含内部索引缓存）
├── lsp_client.gd              # Godot LSP 客户端（供 system/script 与脚本编辑服务使用）
├── impl_project.gd            # 项目级与编辑器聚合级 system 工具实现
└── impl_script.gd             # 脚本级 system 工具实现
```

## 根层共享脚本

`tools/` 根目录当前只保留共享 helper 或尚未完成目录化迁移的旧域脚本，例如：

- `base_tools.gd`
- `plugin_shared.gd`
除 `base_tools.gd` 与 `plugin_shared.gd` 这类共享脚本外，内置工具域的根目录旧入口已经删除；正式入口统一为 `tools/<category>/executor.gd`。

## 文档维护约束

- 新增 executor 目录时，必须同步更新本索引。
- 若某个旧根层脚本完成目录化迁移或被删除，必须在此同步更新。
- 若新增 `plugin_*` 工具或 `custom_tools/` 工作流变化，也必须同步更新本索引和 [用户扩展.md](用户扩展.md)。
