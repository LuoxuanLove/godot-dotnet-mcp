# 目录树与文件职责

本文档从目录树视角说明 `addons/godot_dotnet_mcp` 的主要文件结构和职责分布，帮助维护者快速定位实现入口。

---

## 顶层目录

```text
addons/godot_dotnet_mcp
├─ custom_tools/
├─ docs/
├─ localization/
├─ plugin/
├─ release/
├─ tools/
├─ ui/
├─ plugin.cfg
├─ plugin.gd
└─ README.md
```

---

## 顶层文件

| 路径 | 作用 |
|---|---|
| `plugin.gd` | 插件入口、生命周期总协调、稳定桥接入口与顶层 Dock 调用入口 |
| `plugin.cfg` | Godot 插件声明与版本信息 |
| `README.md` | 对外使用、接入说明与语言切换入口 |
| `docs/en/CHANGELOG.md` / 各语言本地化变更日志入口 | 仓库级版本增量记录与多语言入口，不属于插件包内目录 |
| `.gitignore` | 忽略规则，包括 `.backup/` 等运行期产物 |

## `docs/`

当前公开文档按 locale 组织，每个 locale 保持一致的树形结构：

- `界面/`
- `测试/`
- `流程/`
- `附录/`

文档本身也是项目的一部分，需要和代码同步维护。

### `tools/system/`

系统域目录结构比其他域更复杂，当前已经拆成 executor + impl + 子目录化 project/script：

| 文件 | 职责 |
|---|---|
| `executor.gd` | 调度器：初始化 system 子域执行器，扫描加载 `custom_tools/`，路由 `execute` / `execute_async` 调用 |
| `atomic_bridge.gd` | 原子桥：`call_atomic(executor_name, tool_name, args)` 动态加载下层 executor；包含写保护逻辑（阻止修改 `res://addons/godot_dotnet_mcp/` 内置目录，`custom_tools/` 除外） |
| `impl_editor.gd` | 实现 `system_editor_control`，统一聚合主屏幕切换、编辑器截图、控件枚举、坐标映射、控件本地点击与弹窗交互 |
| `impl_evidence.gd` | 实现 `system_editor_evidence`，提供高层证据 surface 工作流，可捕获 editor、control、popup、active-dialog 或 auto surface，并返回目标、fallback、降级与可见弹窗元数据 |
| `impl_inspector.gd` | 实现 `system_inspector`，通过检视器、编辑器 UI 控件与截图原子工具编排目标选择、可见属性模型列出、唯一属性解析、类型化值读取、值编辑器聚焦、受支持 text/number/bool 写入、验证、截图证据与可信 `run_task` 属性工作流 |
| `impl_settings_dialog.gd` | 实现 `system_settings_dialog`，通过编辑器 UI、截图、弹窗与 Tree 项原子工具编排设置类对话框的打开、状态、搜索、列出/激活标签页、列出/聚焦分类、列出行模型、读取、聚焦值控件、设置与验证可见行值、`run_task` 可信组合任务、聚焦、截图与关闭流程，并覆盖标签页导航、分类导航、只读值断言、值编辑控件聚焦、UI 范围内的值写入验证和截图证据 |
| `impl_runtime.gd` | 实现 `runtime_control` 与统一运行时 I/O 入口 `runtime_step(action=step|capture|input)` |
| `impl_scene.gd` | 实现 `scene_inspect` / `scene_validate` / `scene_analyze` / `scene_patch` |
| `impl_index.gd` | 实现内部索引缓存、`project_symbol_search` 与 `scene_dependency_graph` |
| `impl_project.gd` | 实现 `project_state` / `editor_state` / `project_configure` / `project_lifecycle(action=start|stop)` / `runtime_diagnose` |
| `impl_script.gd` | 实现 `bindings_audit` / `script_analyze` / `script_patch` |

## `custom_tools/`

这是 User 工具目录。典型内容包括：

- 用户脚本
- 自进化脚手架生成结果
- 删除前备份目录 `.backup/`

这部分内容属于运行中可变区域，不应与内置工具域混写。

---

## `release/`

用于承载对外发布相关内容。它不参与插件运行时装配。

---

## 不需要重点关注的文件

以下文件通常不需要在功能维护时单独阅读：

- `*.uid`
- 纯资源 ID 映射文件
- 未被引用的旧测试夹具

但若出现资源失联或 Godot 资源重定向问题，仍需要连同 `.tscn/.gd/.uid` 一起检查。
