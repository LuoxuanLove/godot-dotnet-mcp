- [说明.md](说明.md)：产品概览、安装方式与首次连接步骤。
- [路线图.md](路线图.md)：插件规划方向与版本主题。
- [变更日志.md](变更日志.md)：按版本记录已发布变更。
- [界面/总览.md](界面/总览.md)：Dock 布局与编辑器界面行为。
- [流程/发布运行手册.md](流程/发布运行手册.md)：发布检查清单与版本源规则。
- [测试/总览.md](测试/总览.md)：验证层级与 CI 期望。
- [附录/编码规范.md](附录/编码规范.md)：仓库编码规则与 Windows PowerShell 注意事项。
