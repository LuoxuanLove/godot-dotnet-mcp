## 🧩 Godot .NET MCP v1.4.0：协议重构线初始化

Godot .NET MCP v1.4.0 开启协议重构版本线，并收紧为插件优先的发布表面。最终发布说明会在发布前根据 v1.4.0 实际用户可见的资源、提示词、工具与契约变更补全。

### ✨ 初始亮点

v1.4.0 版本线已准备好承载协议重构改进。最终亮点会在资源、提示词、工具与契约变更完成后，根据实际用户可见内容定稿。

### 📚 Resource-first 协议表面

v1.4.0 版本线把被动上下文、状态和目录发现迁向 MCP Resources，把工作流规划保留在 Prompts，并将公开 Tools 收窄为动作或计算型工作流结果。旧发现调用现在返回明确的替代指引，而不再作为一等公开工具。

### 🧪 可复现插件门禁

面向发布的能力声明会绑定到插件自身可复现的检查：本地化文档验证、manifest 驱动的公开工具护栏、headless MCP 契约以及干净安装验证。这样发布说明只描述可从插件仓库复现的行为。

### ✅ 兼容性与升级提示

该版本线将插件元数据更新到 v1.4.0，并继续面向 Godot 4.6+ .NET 项目。兼容性与升级提示将在 v1.4.0 协议重构表面完成后定稿。
