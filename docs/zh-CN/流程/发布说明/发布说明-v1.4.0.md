## 🧩 Godot .NET MCP v1.4.0：协议重构线初始化

Godot .NET MCP v1.4.0 开启协议重构版本线，并收紧为插件优先的发布表面、resource-first 上下文入口和更强的公开 MCP 行为契约门禁。

### ✨ 发布亮点

v1.4.0 版本线建立协议重构基线：被动上下文迁向 MCP Resources，工作流起手说明保留在 Prompts，公开 Tools 收窄为动作或计算型工作流入口，旧发现调用返回明确替代指引。

### 📚 Resource-first 协议表面

v1.4.0 版本线把被动上下文、状态和目录发现迁向 MCP Resources，把工作流规划保留在 Prompts，并将公开 Tools 收窄为动作或计算型工作流结果。旧发现调用现在返回明确的替代指引，而不再作为一等公开工具。

编辑器 Output 读取也遵循同样的 resource-first 模型：客户端可读取 `godot-dotnet-mcp://logs/editor/output` 或 `godot-dotnet-mcp://logs/editor/errors`，而清空 Output 仍是显式编辑器控制动作，不属于被动 Resource。

### 🧪 可复现插件门禁

面向发布的能力声明会绑定到插件自身可复现的检查：本地化文档验证、manifest 驱动的公开工具护栏、headless MCP 契约以及干净安装验证。这样发布说明只描述可从插件仓库复现的行为。

### ✅ 兼容性与升级提示

该版本线将插件元数据更新到 v1.4.0，并继续面向 Godot 4.6+ .NET 项目。客户端应优先使用新的 Resources 与 Prompts 入口获取被动上下文和工作流规划；旧发现调用会提供迁移指引，而不再作为一等公开工具保留。
