### ✨ Protocol-First MCP Surface

v1.4 线把默认 MCP surface 切到 2025-11-25 目标。被动上下文、状态、日志和目录发现迁入 Resources；工作流起手说明保留在 Prompts；Tools 聚焦动作或计算型 workflow result。旧 discovery calls 返回明确替代指引，而不再作为一等 public tools。

### 🌊 Streamable HTTP 与 Stdio

默认 endpoint 仍是 `http://127.0.0.1:3000/mcp`，但语义已对齐 Streamable HTTP：protocol/session headers、JSON/SSE `Accept` negotiation、Origin/CORS checks、GET SSE streams、可恢复 event history、有限 POST SSE responses、heartbeat events、queued server-to-client delivery 和 `DELETE /mcp` session termination。Stdio 默认改为 newline-delimited JSON-RPC，旧 `Content-Length` framing 仅作为显式 compatibility mode 保留。

### 🧭 Resource 与 Prompt UI

Dock 现在把 Resources 和 Prompts 作为一等页签展示，包含协议目录计数、可复制 ID、resource preview、prompt 参数输入、生成 prompt preview 和受限 icon rendering。Tools 页也消费共享 catalog metadata，用于 titles、icons、annotations、input schemas、output schemas、preview、search 和 schema copy actions。

### 🧠 C# 语义 Runtime

Asset Library 或准备好的 addon 安装后，C# semantic tooling 仍通过隔离 Roslyn runtime bundle 可用。随附 addon 不会把 Roslyn 和 bridge source files 放进宿主项目 compile surface，同时保留 semantic read 与 patch workflows。

### ✅ 兼容性与验证

该版本线为退场 discovery tools 保留 compatibility guidance，强化 HTTP/stdio JSON-RPC 行为，并新增 public tool removals、root monolith closure、catalog facts、optional capabilities、changelog structure、Roslyn runtime bundle shape 和 clean install validation 护栏。
