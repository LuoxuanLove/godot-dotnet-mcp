## 🧩 Godot .NET MCP v1.4.0：协议重构线初始化

Godot .NET MCP v1.4.0 开启协议重构版本线，同时保留第一批用户可见的验证改进：读者可以从 README 与本地化入口页查看公开 Godot .NET 项目示例，最终发布说明会在发布前根据 v1.4.0 实际用户可见变更补全。

### ✨ 初始亮点

v1.4.0 版本线已准备好承载协议重构改进。最终亮点会在资源、提示词、工具与契约变更完成后，根据实际用户可见内容定稿。

### 🖼️ 真实项目示例

README 现在加入了独立的“真实项目验证”小节，在项目说明旁展示截图。链接到的 CoGDSex 仓库是一个记录真实开发工作的 Godot .NET 游戏项目，而不是合成演示。

### 🌐 本地化入口

同一验证说明也同步到简体中文、日文与韩文入口页，因此使用任一受支持文档语言的读者都能访问同一个项目示例，并理解它为什么能说明插件稳定性。

### ✅ 兼容性与升级提示

该版本线将插件元数据更新到 v1.4.0，并继续面向 Godot 4.6+ .NET 项目。兼容性与升级提示将在 v1.4.0 协议重构表面完成后定稿。
