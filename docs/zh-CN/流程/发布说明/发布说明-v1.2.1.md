## 🧩 Godot .NET MCP v1.2.1：更容易触达编辑器设置

该版本线首先让 Agent 更容易直接进入编辑器配置界面。正式发布前，本说明会继续根据相对 `v1.2.0` 的实际用户可见变更补全。

### ✨ Project Settings 控制

`system_editor_control` 现在可以打开 Project Settings 并激活指定标签页，包括 Plugins 标签页，不再需要依赖坐标式菜单自动化。

新的编辑器 UI 动作扩展现有 `system_editor_control` 表面，插件版本继续保持在 `1.2.1` 开发版本线。
