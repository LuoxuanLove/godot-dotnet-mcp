# 服务与路由

本文档描述插件的服务入口、会话分层与路由方向。

当前核心原则是：

- 插件内 MCP HTTP 服务端是唯一公开入口
- 插件内 Roslyn 运行在 Godot .NET 运行时内部，语法优先
- 无外部宿主、无子进程

---

## 服务入口

### 公开入口

插件 MCP 服务端由 `plugin/runtime/mcp_http_server.gd` 提供：

- HTTP 监听在 `http://127.0.0.1:3000/mcp`（或当前配置端口）
- 工具注册和分发由 `tools/core/tool_loader.gd` 管理

外部 MCP 客户端应连接：

```text
http://127.0.0.1:3000/mcp
```

### 内部组件

插件内部组件：

- `plugin/runtime/mcp_http_server.gd` — MCP HTTP 服务端
- `plugin/runtime/server_runtime_controller.gd` — 服务生命周期管理
- `plugin/runtime/plugin_roslyn_service.gd` — 插件内 Roslyn 服务 façade
- `tools/core/tool_loader.gd` — 工具目录与装载

---

## 工具分层

### Editor-attached

所有工具都依赖实时编辑器状态：

- `system_*` — 项目快照、场景分析、脚本结构检查、C# 绑定审计、符号搜索
- `script_*` — 脚本读写、C# 语法分析
- `scene_*` — 场景查询与修改
- `node_*` — 节点操作

### 插件内部开发能力

以下能力用于插件内诊断和维护：

- `plugin_runtime_*`
- `plugin_developer_*`
- `plugin_evolution_*`

---

## 会话模型

插件不管理外部会话概念，所有工具直接在编辑器进程中执行。

Godot 可执行路径策略：

- Godot 路径来自用户显式配置或本机常见目录发现
- 不做广范围磁盘扫描
- 机器相关路径不得固化进发布产物

---

## 路由责任

### 插件

负责：

- MCP HTTP 服务端监听与请求处理
- 工具目录注册与分发
- 在实时编辑器环境中执行工具
- 提供本地服务与诊断面板
- 维护插件侧工具运行时和 `user_*` 扩展

### 插件内 Roslyn

负责：

- C# 语法树解析（syntax-only，无 SemanticModel）
- 类型、方法、导出成员提取
- `script_inspect`、`script_exports`、`script_edit_cs` 等 C# 工具的语法分析

---

## 错误语义

围绕 editor-required 工具，插件返回结构化错误：

- `project_not_selected`
- `godot_executable_not_found`
- `script_not_found`
- `parse_error`
- `binding_audit_error`

---

## 当前实现边界

- 插件使用 HTTP MCP 端点
- C# 分析使用插件内 Roslyn（syntax-first）
- `dotnet_bridge/` 是共享 .NET 库，不是外部可执行文件
