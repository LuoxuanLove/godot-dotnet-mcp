## 🧩 Godot .NET MCP v1.2.1: Verified Editor UI Automation

この version line では editor UI automation を改善し、client が次の workflow に進む前に Godot editor 内の visible state を待てるようにします。Agent は既存の editor control で操作したあと、期待する UI condition が実際に現れたかを検証できます。

### ✨ 実際の UI 状態を待機

`system_editor_control` に `wait_for_ui` を追加しました。control の存在、可視性、text matching、enabled / disabled state を有界にポーリングできます。成功時は一致した control summary と timing detail を返し、timeout 時は最後に観測した payload を返すため、client は locator や次の action を調整できます。

### 🔧 より安全な automation loop

新しい wait action は menu、popup、click、hover、text entry control と組み合わせて使え、OS mouse automation は不要です。editor dialog を開く、setting を filter する、一時 panel を確認する、といった workflow を Godot 内で検証しやすくします。

### 🧭 Settings Dialog Navigation

`system_settings_dialog` は Project Settings と Editor Settings 向けの high-level workflow を追加します。client は editor menu から settings surface を開き、dialog の可視化を待ち、候補 setting row を検索し、返された result に focus し、evidence を capture して、setting value を直接書き込まずに surface を閉じられます。

この workflow は `list_rows` で読み取り専用 row model も返せるようになり、将来の値編集レイヤーの前に、可視 settings-like control を保守的な confidence と evidence 付きで要約します。

さらに `read_value` で一意に一致した可視 row の現在値を読み取り、row と value-control の evidence とともに text、bool、number、enum の型付き payload を返せます。setting value は引き続き直接書き込みません。

対応している一意の可視 row は、`set_value` で text、number、bool control を編集できます。この workflow は editor UI control 経由で書き込み、操作後に row を再観測するため、client は click や text edit が成功したと仮定せずに変更後の値を確認できます。

### ✅ Compatibility and Upgrade Notes

この変更は public tool schema を拡張するだけです。既存の `system_editor_control` action は引き続き利用でき、`wait_for_ui` を呼ばない client は request を変更する必要がありません。
