## 🧩 Godot .NET MCP v1.2.1: Editor Settings Reach

この version line は、Agent が editor configuration surface に直接到達しやすくするところから始まります。正式リリース前に、`v1.2.0` 以降の実際の user-visible change に基づいてこの note を補完します。

### ✨ Project Settings Control

`system_editor_control` は Project Settings を開き、Plugins tab を含む指定 tab を有効化できるようになりました。coordinate-based menu automation に頼る必要が減ります。

### ✅ Compatibility and Upgrade Notes

新しい editor UI action は既存の `system_editor_control` surface を拡張し、plugin version は `1.2.1` development line のままです。
