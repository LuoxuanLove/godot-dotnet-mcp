## 🧭 Godot .NET MCP v1.4.0: 実プロジェクトでの検証

Godot .NET MCP v1.4.0 は、plugin の実プロジェクト検証を読者が確認しやすくするところから始まります。README と localized entry page から、実際の開発作業を記録する公開 Godot .NET project に移動でき、より大きな editor workflow の中で plugin が使われている様子を確認できます。

### 🖼️ 実プロジェクト例

README には、project note の横に screenshot を置いた専用の Real Project Validation section が追加されました。リンク先の CoGDSex repository は、合成 demo ではなく、実際の開発作業を記録する Godot .NET game project として示されています。

### 🌐 ローカライズされた入口

同じ検証説明は Simplified Chinese、Japanese、Korean の entry page にも追加されています。どの対応 documentation language を使う読者でも、同じ project example に移動し、それが plugin stability にとってなぜ重要かを理解できます。

### ✅ Compatibility and Upgrade Notes

この documentation update は Godot / .NET compatibility expectation を変更しません。Godot .NET MCP は引き続き Godot 4.6+ .NET projects を対象にし、release-note source は v1.3.0 release 後の v1.4.0 version line を追跡します。
