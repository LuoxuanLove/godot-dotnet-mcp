### ✨ Initial Highlights

v1.4.0 line は protocol-refactor improvement を集める準備ができています。resource、prompt、tool、contract の completed user-visible changes が確定したら、final highlights を実際の内容から仕上げます。

### 📚 Resource-first Protocol Surface

v1.4.0 line は passive context、state、catalog discovery を MCP Resources に寄せ、workflow planning を Prompts に残し、public Tools を action または computed workflow result に絞ります。legacy discovery call は first-class public tool として残るのではなく、明示的な replacement guidance を返します。

### 🧪 Reproducible Plugin Gates

Release-facing claims は plugin-owned checks に結び付けます。localized documentation validation、manifest-backed public-tool guardrails、headless MCP contracts、clean install verification によって、release notes は plugin repository から再現できる behavior だけに集中します。

### ✅ Compatibility and Upgrade Notes

この version line は plugin metadata を v1.4.0 に更新し、引き続き Godot 4.6+ .NET projects を対象にします。compatibility and upgrade notes は v1.4.0 protocol-refactor surface の完成後に確定します。
