## 🧩 Godot .NET MCP v1.4.0: Protocol Refactor Line Initialized

Godot .NET MCP v1.4.0 は protocol-refactor line を開始し、より厳密な plugin-first release surface、resource-first context entry、public MCP behavior の強い contract gate を導入します。

### ✨ Release Highlights

v1.4.0 line は protocol-refactor baseline を定めます。passive context は MCP Resources へ移り、workflow orientation は Prompts に残り、public Tools は action と computed workflow entry に絞られ、legacy discovery call は明示的な replacement guidance を返します。

### 📚 Resource-first Protocol Surface

v1.4.0 line は passive context、state、catalog discovery を MCP Resources に寄せ、workflow planning を Prompts に残し、public Tools を action または computed workflow result に絞ります。legacy discovery call は first-class public tool として残るのではなく、明示的な replacement guidance を返します。

Editor Output の読み取りも同じ resource-first model に従います。clients は `godot-dotnet-mcp://logs/editor/output` または `godot-dotnet-mcp://logs/editor/errors` を読み取り、Output clear は passive Resource ではなく明示的な editor-control action として扱います。

### 🧪 Reproducible Plugin Gates

Release-facing claims は plugin-owned checks に結び付けます。localized documentation validation、manifest-backed public-tool guardrails、headless MCP contracts、clean install verification によって、release notes は plugin repository から再現できる behavior だけに集中します。

v1.4 の install surface は C# syntax support も first-class plugin capability として扱います。Asset Library と direct source-copy install は `plugin/runtime/roslyn_runtime/` の isolated Roslyn runtime bundle を保持し、plugin Roslyn / bridge C# source tree は host project compile surface に入れません。

### ✅ Compatibility and Upgrade Notes

この version line は plugin metadata を v1.4.0 に更新し、引き続き Godot 4.6+ .NET projects を対象にします。client は passive context と planning には新しい Resources と Prompts entry を優先し、legacy discovery call は first-class public tool ではなく migration guidance として扱います。
