### ✨ Protocol-First MCP Surface

v1.4 line は default MCP surface を 2025-11-25 target に移します。passive context、status、logs、catalog discovery は Resources に置かれ、workflow orientation は Prompts に残り、Tools は actions または computed workflow results に集中します。legacy discovery calls は first-class public tools ではなく明示的な replacement guidance を返します。

### 🌊 Streamable HTTP and Stdio

default endpoint は `http://127.0.0.1:3000/mcp` のままですが、semantics は Streamable HTTP に合わせています。protocol/session headers、JSON/SSE `Accept` negotiation、Origin/CORS checks、GET SSE streams、resumable event history、finite POST SSE responses、heartbeat events、queued server-to-client delivery、`DELETE /mcp` session termination を含みます。Stdio は newline-delimited JSON-RPC を default にし、legacy `Content-Length` framing は explicit compatibility mode としてのみ残します。

### 🧭 Resource and Prompt UI

Dock は Resources と Prompts を first-class tabs として表示します。protocol catalog counts、copyable IDs、resource previews、prompt argument inputs、generated prompt previews、bounded icon rendering を含みます。Tools tab も shared catalog metadata を使い、titles、icons、annotations、input schemas、output schemas、previews、search、schema copy actions を表示します。

### 🧠 C# Semantic Runtime

Asset Library または prepared addon install 後も、C# semantic tooling は isolated Roslyn runtime bundle によって利用できます。shipped addon は Roslyn と bridge source files を host project compile surface から外しつつ、semantic read / patch workflows を維持します。

### ✅ Compatibility and Validation

この line は retired discovery tools の compatibility guidance を維持し、HTTP/stdio JSON-RPC behavior を harden し、public tool removals、root monolith closure、catalog facts、optional capabilities、changelog structure、Roslyn runtime bundle shape、clean install validation の guardrails を追加します。
