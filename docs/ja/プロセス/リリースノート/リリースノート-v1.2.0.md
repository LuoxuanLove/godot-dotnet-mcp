## 🧩 Godot .NET MCP v1.2.0: ローカライズ文書ツリーと i18n 検証

この release は文書品質に重点を置いています。ローカライズされた文書ツリーを、すぐ使えるユーザー向け参照資料として整え、各 locale tree が構造的にそろい、自己完結するよう検証を強化しました。

### ✨ ハイライト

- 英語、簡体字中国語、日本語、韓国語の完全なローカライズ文書ツリーを追加しました。
- 韓国語文書セットを拡張し、対象ページも短い要約ではなく完全な翻訳として読めるようにしました。
- locale file parity、Markdown のリンク先、locale 間リンクの混入を対象にした docs i18n 検証を追加しました。

### 🔧 修正

- service routing、.NET support、UI flow、tool-domain index に関する英語と日本語の文書 facts を修正しました。
- 壊れていた、または古くなっていたローカライズ用のプレースホルダーを、現在のユーザー向け内容に置き換えました。
- 日本語 README の無効な screenshot reference を削除しました。

### ✅ 互換性とアップグレード注意事項

- この release は文書内容と検証のみを変更します。
- plugin behavior、file layout、tool schema の変更は含みません。
- 既存の install に migration は不要です。
