## 🧩 Godot .NET MCP v1.2.0: 再接続を意識した Agent ワークフロー

この release は、複数の MCP client や Agent session が同時に plugin を使う場面での復旧を分かりやすくします。maintenance window reporting、reconnect guidance、transport resilience、health diagnostics、update-sync refresh behavior、editor UI control を強化し、plugin reload や update sync の後に client が安全に再接続して tool list を取り直し、登録済み editor main screen と visible な Godot UI flow を引き続き操作できるようにしました。

### ✨ ハイライト

- `system_editor_control` に top menu control を追加し、Agent が editor menu を一覧し、`MenuButton` を開き、text または index で `PopupMenu` item を選択してから popup inspection や text/button action を続けられるようにしました。
- health、plugin reload、plugin update の response に maintenance window metadata を追加し、一時的な切断、retry timing、tool list refresh requirement を client が判別できるようにしました。
- `/health` に HTTP client session identity と request audit field を追加し、安定した connection ID、request ID、client summary、active session、最近切断された session を確認できるようにしました。
- `system_tool_activity` を追加し、並行作業を調整するときに、HTTP と stdio の tool call における実行中の記録、最近の完了履歴、実行順序、任意の Agent 自己申告コンテキストを確認できるようにしました。
- 対応する Dock 言語で reconnect guidance をローカライズしました。
- editor plugin session diagnostics を追加し、client が third-party EditorPlugin の project setting、live editor state、visible UI hint、保護付き enable / disable behavior を確認できるようにしました。
- main-screen button の列挙、登録済み plugin main screen への切り替え、distraction-free mode の制御を行う editor-control action を追加しました。
- 現在の plugin UI、tool、binding reference に合わせて localized docs tree を整えました。
- visible な `PopupMenu` item を index、id、完全一致 text で選択する high-level editor-control action を追加しました。
- locale file parity、Markdown のリンク先、locale 間リンクの混入を対象にした docs i18n 検証を追加しました。

### 🔧 修正

- service routing、.NET support、UI flow、tool-domain index に関する英語と日本語の文書 facts を修正しました。
- plugin update sync が file を書き込んだ後、plugin lifecycle reload を schedule する前に Godot editor file system を refresh するようにしました。
- popup menu automation が hidden popup、disabled item、separator、submenu row、競合する selector、重複 text item を誤って実行しないよう保護しました。
- 壊れていた、または古くなっていたローカライズ用のプレースホルダーを、現在のユーザー向け内容に置き換えました。
- 日本語 README の無効な screenshot reference を削除しました。
- HTTP keep-alive handling を改善し、async tool execution の後も、すでに buffer された pipelined request が drain され続けるようにしました。
- multi-client recovery 向けの reconnect backpressure safeguard を追加し、pending request buffer の上限と response write failure 後の connection cleanup を行います。
- stdio burst processing と lifecycle reload scheduling を強化し、古い response や失敗した reload schedule が誤解を招く pending state を残さないようにしました。

### ✅ 互換性とアップグレード注意事項

- 既存の tool name は互換性を維持します。
- `system_editor_control` に `list_menus`、`open_menu`、`select_menu_item` が追加されたため、tool schema version が更新されました。
- `system_editor_plugin_control` は追加 tool です。この plugin 自身には汎用 self-disable flow ではなく、専用の plugin reload / update tool を使ってください。
- Update sync は lifecycle reload step の前に editor へ plugin file の rescan を要求します。
- client は update sync や plugin reload 中に health を poll し、transport が切断された場合は再接続し、maintenance window が schema stale の可能性を示す場合は tool list を再取得してください。
- client は tool call に短い `_mcp_context` object を渡して協調用の説明を付けられます。これは自己申告コンテキストであり、認証ではありません。
- plugin main screen へ切り替えるには、現在の editor session がその main screen をすでに登録している必要があります。
- Popup menu selection は tool-schema action を追加します。アップグレード後は再接続し、tool list を再取得してください。
- file layout migration は不要です。
- 既存の install に migration は不要です。
