# Godot .NET MCP 文書概要

この文書セットは、プラグインの公開利用体験に焦点を当てます。対象は、インストール、エディター UI、MCP クライアント設定、リリース手順、テスト検証、運用向け参考情報です。

すばやく読み始める場合は、次の入口を使ってください。

- [はじめに.md](はじめに.md): 製品概要、インストール方法、初回接続手順。
- [ロードマップ.md](ロードマップ.md): プラグインの計画とバージョンテーマ。
- [変更履歴.md](変更履歴.md): リリースごとの変更内容。
- [インターフェース/概要.md](インターフェース/概要.md): Dock の配置とエディター UI の挙動。
- [プロセス/リリース運用手順.md](プロセス/リリース運用手順.md): リリース確認項目とバージョンソースの規則。
- [テスト/概要.md](テスト/概要.md): 検証レイヤーと CI の期待値。
- [付録/エンコーディング規約.md](付録/エンコーディング規約.md): リポジトリのエンコーディング規則と Windows PowerShell の注意点。
