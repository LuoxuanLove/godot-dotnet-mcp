## [Unreleased] ([2.0.0])

対象バージョン: 2.0.0。

### Added

- isolated Roslyn runtime bundle を追加し、Asset Library と prepared addon install でも C# semantic read / patch workflow を維持しつつ、plugin Roslyn や bridge source files を host project compile surface に入れないようにしました。
- MCP 2025-11-25 Resources、Resource Templates、Prompts、Tools metadata を追加しました。title、icon、annotation、input schema、output schema、JSON Schema 2020-12 declaration を含みます。
- Dock Resources / Prompts tabs を追加し、protocol catalog counts、ID copy actions、resource previews、prompt argument inputs、generated prompt previews、bounded icon rendering を提供します。
- read-only editor log resources `godot-dotnet-mcp://logs/editor/output` と `godot-dotnet-mcp://logs/editor/errors` を追加しました。
- `runtime_step(action=input)` に mouse move / click support を追加し、tool schema に viewport coordinate fields を公開しました。
- diagnostic code、recommended action、follow-up tool hint を含む structured User-tool recovery diagnostics を追加しました。
- idle-process と User-tool watch diagnostics を追加し、毎回の Dock refresh で重い runtime query を強制せずに frame budget、scan slices、watcher progress を self diagnostics で報告できるようにしました。
- Config tab に Antigravity client support を追加しました。app detection、app launch、`.gemini/config/mcp_config.json` への `godot-mcp` one-click write / remove、copied MCP configuration、setup directory hints を提供します。
- lightweight Godot `Performance` custom monitors を追加し、plugin process time、slow-frame count、1 秒間隔の engine samples を Debugger Monitor と self diagnostics から確認できるようにしました。

### Changed

- default MCP protocol baseline を `2025-11-25` に変更しました。initialize metadata、tool-name validation、schema dialect policy、explicit optional-capability boundaries を含みます。
- default stdio transport を newline-delimited JSON-RPC に変更し、legacy `Content-Length` framing は explicit compatibility mode としてのみ残しました。
- default HTTP endpoint `127.0.0.1:3000/mcp` を MCP Streamable HTTP semantics に寄せました。protocol/session headers、JSON / SSE `Accept` negotiation、Origin/CORS checks、GET SSE streams、resumable event history、finite POST SSE responses、heartbeat events、queued server-to-client delivery、`DELETE /mcp` session termination を含みます。
- public discovery を resource-first / prompt-first に変更しました。passive help、activity、catalog、editor-log、plugin maintenance、scene validation discovery は legacy public discovery tools ではなく Resources、Prompts、canonical action tools を使います。
- `tools/list` を schema、annotation、output metadata 付きの flat callable tool list に変更し、tree/group presentation data は catalog resources と shared Dock presentation snapshots に移しました。
- catalog snapshots、catalog resources、`/api/tools`、Dock model metadata、Tools tab preview/search/schema-copy paths を `ToolCatalogManifest` と `ToolCatalogSnapshotService` の shared catalog fact path に統一しました。
- Dock Tools rows、action previews、Resources、Prompts、schema inspection は private UI catalog facts を再構築せず shared protocol metadata を render するように変更しました。
- Dock Tools tab は Agent Tools call surface を default にし、executor 構成と legacy/public-tool diagnostics は separate Internal / Diagnostics views で確認するように変更しました。
- Dock Resources / Prompts tabs は explicit presentation trees を消費し、shared protocol metadata に基づいて resource URI、resource template、workflow prompt、prompt argument を grouping するように変更しました。Dock 側で URI や名前から分類を推測しません。
- Dock Resources / Prompts tabs に Catalog / Diagnostics views を追加し、読みやすい protocol entries と source / visibility / callability / group metadata を切り替えられるようにしました。
- editor startup と idle refresh を軽量化し、auto-start を `_enter_tree` の同期 path から外し、非 active Dock tab を lazy-load し、MCP server startup を軽く保ち、HTTP service bundle と tool runtime を on demand で読み込み、disabled-tool filter は runtime initialization まで cache し、Resources / Prompts protocol list projection が loader を触らないようにし、現在の Dock tab に必要な catalog projection だけを構築し、User-tool polling と scan slices をより保守的に進めることで large projects での editor stalls を減らしました。
- Dock Tools refresh checks と User-tool runtime definition comparison は reusable lightweight signatures を使うように変更し、idle refresh 中に full presentation tree、metadata map、tool definition array を繰り返し serialize しないようにしました。
- Dock catalog model refresh checks を deterministic lightweight signatures に変更し、各 tool entry を serialize せずに nested schema と presentation metadata の変更を検出しながら、繰り返しの Dock refresh work を減らしました。
- shared tool presentation signatures は presentation nodes、groups、metadata maps を JSON serialize せず、nested metadata invalidation を維持するように変更しました。
- C# semantic tooling の production runtime path は isolated Roslyn runtime process のみに変更し、source-tree / direct-copy install が plugin の in-process C# facade を host project 内で自動 load しないようにしました。
- User-tool polling は runtime loading が無効なとき synchronous scan を skip し、大きな directory walk を budgeted slices に分割するように変更しました。これにより idle refresh の応答性を保ちます。
- User-tool watch scanning と fallback runtime scanning を dedicated scan service に移し、file metadata traversal、slice budgets、scan diagnostics を watch polling / reload coordination から分離しました。
- audio、animation、signal、TileMap、UI、filesystem、node、project、resource、scene、group、geometry、material、lighting、navigation、particle、physics、shader、debug、editor domain implementations を split executors に変更し、debug/editor は thin compatibility wrappers として残しました。
- AtomicBridge、`MCPToolLoader`、stdio routing、plugin lifecycle wiring、reload handling、runtime context wiring、status/query projections、User-tool maintenance を dedicated services に分離しつつ public facades を維持しました。
- MCPToolLoader lifecycle tick の budget、interval selection、tick performance counters を dedicated budget service に移し、runtime tick side effects は loader lifecycle path に残しました。
- MCPToolLoader service readiness checks を変更し、status、catalog、tick、execution の hot path では service factory wiring の繰り返しを避けつつ、script reload 後は services を再構築できるようにしました。
- plugin update の refs、sync、compare workflow の state transitions を dedicated transition service に移し、Dock と MCP update status fields は維持しました。
- plugin update endpoint、archive、timeout、marker、addon-root の facts を dedicated endpoint config service に移し、これらの GitHub / update constants を plugin entrypoint に保持しないようにしました。
- plugin update helper ownership をさらに整理し、未使用の branch-ref、archive-ref、ref-list wrapper は dedicated update services に残し、plugin entrypoint から外しました。
- project と bundled plugin license を v2.0 line で MIT から Apache-2.0 に変更しました。

- Config tab の one-click CLI setup actions を修正し、client command を non-blocking process path で実行し、panel 内に即時 status を表示するようにしました。command exit まで editor が固まることを避けます。
- Config tab の直接 config write / remove actions を修正し、file preflight と writeback は panel が visible running state に入ってから開始するようにしました。遅い config path で click 後に固まったように見える状況を避けます。
- Dock Tools tab の first-open responsiveness を修正し、最初は active tool presentation view だけを構築し、Internal Executors / Diagnostics trees は対応する view が選択されるまで遅延します。
- Dock Tools tab の repeated refresh を修正し、tool catalog が変わっていない場合は lightweight catalog revision で直前の presentation model を再利用し、active tab refresh ごとに full tool snapshot を再構築しないようにしました。
- Dock Tools tab の search responsiveness を修正し、同一 frame 内の連続 query 変更を 1 回の deferred tree render にまとめ、keystroke ごとに catalog を clear / rebuild しないようにしました。
- Dock status snapshots を修正し、lightweight views は cached lifecycle context を再利用し、active tab が明示的に必要とする場合だけ heavy server diagnostics を呼び出すようにしました。
- update / hot reload 後の MCP tool discovery recovery を修正し、`tools/list` / `tools/call` が空の tool registry を lazy initialize し、重複する editor automation calls は `editor_automation_busy` で即時失敗し、idle GDScript LSP tick log spam によって editor や MCP client が固まったように見える状況を避けるようにしました。
- idle runtime tick を修正し、HTTP / stdio transports が loaded tool executors と GDScript LSP diagnostics を editor frame ごとに駆動しないようにしました。lifecycle tick timing も performance diagnostics に公開されます。

## [1.3.0] - 2026-06-08

### Added

- v1.3.0 の semantic editor automation model を追加しました。editor UI guidance は semantic workflow を最優先し、control-level focus/text/value/popup action を次に使い、control-local mouse / pointer event は fallback としてのみ使うようにします。
- `system_editor_control(action="wait_for_ui")` を追加しました。client は automation workflow を続行する前に、実際の editor control を存在、可視性、text、enabled / disabled state で待機できます。
- `system_editor_control(action="get_popup")` と `system_editor_control(action="capture_popup")` を追加しました。返された popup path から可視の floating editor popup / window を inspect / crop できます。
- `system_editor_control` と low-level `ui_control` の click action に click fallback observation evidence を追加しました。dispatch された input event、Button-like target の click 前後 state、観測された control signal、activation evidence がない場合の hint を返します。
- `system_editor_evidence` を追加しました。editor、control、popup、active-dialog、automatic surface の高レベル visual evidence workflow で、target、fallback、degradation、visible-popup、capture-policy metadata を明示します。
- `system_settings_dialog` を追加しました。Project Settings / Editor Settings 向けに open/status/search/navigation、tab/category focus、row model、row resolution、value read/focus/set/verify、surface capture、close、trusted `run_task` orchestration を提供します。
- `system_inspector` を追加しました。Inspector の visible property model、unique property resolution、typed value read、value focus、guarded text/number/bool write、verification、capture、current/prepared target 向け trusted property task を提供します。
- `system_project_lifecycle(action=start|stop)` を canonical な project runtime session lifecycle entry として追加しました。marker validation、auto-stop、stop control、foreground-window fallback metadata、runtime capability context を含みます。
- `system_tool_catalog` を追加しました。client は公開 tool を query、category、domain で検索し、match reason、action、parameter、visibility、enabled state、optional schema を確認できます。
- `system_tool_activity` の query filter と slow/failure diagnostics を追加しました。client は state、tool、slow-call threshold で running / recent call を確認できます。
- User tool naming diagnostics を追加しました。User tool listing、scaffold preview、compatibility report で declared name、normalized name、public MCP tool name を表示します。
- `system_scene_inspect` を追加しました。`validate`、`analyze`、`full` action を持つ統一 read-only scene inspection entry で、既存の scene validation / analysis tool も維持します。
- `system_plugin_maintenance` を追加しました。status、reload、update-status、update-reference refresh、update-source selection、update-start workflow をまとめる canonical high-level plugin maintenance entry です。
- project configuration inspection を追加し、export preset と個別 input action を読み取れるようにしました。sensitive export option key と local absolute export path は redact します。
- MCP resource と resource template の metadata をローカライズし、`resources/list` と `resources/templates/list` が hard-coded English ではなく現在の plugin language に従うようにしました。
- v1.4 canonical MCP resources を追加し、guide discovery、project / editor state、activity status / recent read、exposed / visible tool catalog を扱えるようにしました。既存の compatibility resource URI は維持します。
- Config client card 向けに安定した capability matrix を追加し、support level、利用可能な action metadata、note key を含めました。
