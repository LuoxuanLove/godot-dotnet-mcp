# コア実装

この文書は、`localization/`、`plugin/config/`、`plugin/runtime/`、`custom_tools/`、そして shared helper module の実装関係をまとめます。

---

## 何をまとめるか

コア実装は次の 5 つの塊で考えるとわかりやすいです。

1. localization
2. plugin configuration
3. plugin runtime
4. custom tools
5. shared helper

---

## localization

`localization/` は plugin 内文言の source of truth です。

- Dock、page、tool、diagnostic の label を language ごとに持つ
- editor の自動翻訳に頼らず、plugin 自身が出す text を管理する
- tool name、summary、action、status を locale ごとにそろえる

この層は、単に text を並べるだけではなく、UI の意味を壊さないためにあります。

---

## plugin/config/

`plugin/config/` は、設定保存と client configuration の実務を担当します。

- `settings_store.gd` は settings file と custom profile を読む / 書く
- `client_config_service.gd` は Config page の出力と write / copy の流れをまとめる
- `config_paths.gd` は `user://` 配下の file path を扱う

ここでは、UI から直接 file IO をしないことが大事です。

---

## plugin/runtime/

`plugin/runtime/` は、service、state、control、diagnostic、router をまとめる中心です。

- `plugin_runtime_state.gd` は今の runtime state を持つ
- `server_runtime_controller.gd` は service の start / stop / restart をまとめる
- `mcp_http_server.gd` は実際の HTTP + MCP listener になる
- `mcp_resources_service.gd` と `mcp_prompts_service.gd` は native MCP surface を出す
- `plugin_reload_coordinator.gd` は完全 reload を手伝う
- `runtime_control_service.gd` は `system_runtime_*` の editor 側調整をまとめる

この directory の役目は、plugin の中心的な挙動を UI から切り離して、まだ十分読める形で保つことです。

---

## custom_tools/

`custom_tools/` は project 専用の user tool を置く場所です。

- `user_*` の GDScript tool を hot load できる
- project ごとに独自の MCP capability を足せる
- plugin 本体を触らずに機能を広げられる

この directory は、built-in tool とは分けて考えます。

---

## shared helper

shared helper は、各層で何度も出る共通処理をまとめる場所です。

- path resolve
- JSON / Variant normalize
- node serialize
- diagnostic helper
- presentation helper

同じ処理をいろいろな script に重複させないためにあります。

---

## 実装の流れ

今の理想的な流れは次です。

1. localization が表示 text を持つ
2. config と runtime が state と persistence を持つ
3. helper がよくある共通処理を持つ
4. custom tool が project 専用の拡張を足す
5. UI はそれらを model として受け取る

---

## 保守のポイント

- plugin の文字列を scene に埋め込まない
- 設定の file path を UI と runtime に散らして書かない
- custom tool の load と built-in tool の load を混ぜすぎない
- shared helper に業務 logic を入れすぎない
