# Tool Domain Index

この文書は、すべての tool domain directory、executor、shared root script、代表的な tool を一覧できます。

---

## 見方

tool domain は、directory の並びと公開 tool の両方から把握します。

- domain directory は実装の居場所
- executor はその domain の入口
- shared root script は共通の helper や bridge

---

## 代表的な domain

### `system`

- project、scene、script、runtime、diagnostic の高レベル flow
- 主要な公開入口

### `scene`

- scene 構造の読み取りと修正
- binding と audit

### `script`

- script の inspect と edit
- C# の syntax-first analysis

### `node`

- node の query、操作、構造変更

### `plugin_runtime`

- plugin の runtime state、update、reload、self-diagnostic

### `plugin_evolution`

- update source、release flow、version-aware maintenance

### `plugin_developer`

- 開発者向けの診断、保守、補助機能

### `user`

- project 専用の `user_*` tool

---

## 主要 file の見つけ方

domain を追うときは、だいたい次の順で見ます。

1. `tools/<domain>/executor.gd`
2. `tools/<domain>/catalog.gd`
3. `tools/core/tool_loader.gd`
4. `tools/tool_manifest.gd`
5. 必要なら shared helper

---

## directory と責務の関係

| 領域 | 役割 |
|---|---|
| `tools/system/` | 高レベル公開入口と atomic helper の橋渡し |
| `tools/scene/` | scene の query、audit、binding |
| `tools/script/` | script の inspect、analysis、patch |
| `tools/node/` | node 操作 |
| `tools/plugin_runtime/` | plugin の runtime state、self-diagnostic、reload |
| `tools/plugin_evolution/` | update source、release flow、version-aware maintenance |
| `tools/plugin_developer/` | 開発者向けの診断と補助機能 |
| `tools/user/` | user tool の管理 |
| `tools/shared/` | domain をまたぐ共通 helper |

---

## 何を覚えておくといいか

- tool を探すときは、まず domain と category を見る
- executor は実際の入口だが、そこだけ見ても全体像はつかみにくい
- shared root script に本当の業務 logic が増えすぎていたら、再分割の合図
