# Script と Scene の分析

この文書は、`script_*`、`scene_bindings`、`scene_audit` の分析 flow を説明します。

---

## 何を見たいのか

script と scene の分析は、C# export binding、NodePath、resource reference、scene 構造の問題を見つけるためにあります。

---

## `script_*`

`script_*` は script の中身を調べる entry です。

- script の構造
- class 名
- base type
- method
- enum
- export member

Roslyn の syntax-first analysis を使い、`SemanticModel` は使いません。

---

## `scene_bindings`

`scene_bindings` は、今の scene か指定した scene の binding 状態を調べます。

- node が script とどうつながっているか
- export された値が scene にどう入っているか
- binding の欠落や不整合がないか

---

## `scene_audit`

`scene_audit` は、scene 全体を構造化して診断します。

- scene tree の問題
- resource reference の問題
- node path の不整合
- C# custom Resource script の食い違い

---

## 補助 tool

状況によっては次も組み合わせます。

- `node_query`
- `scene_hierarchy`
- `script_references`

これらは、調べる範囲を少しずつ狭めるのに役立ちます。

---

## よくある使い方

1. まず `script_inspect` で script 構造を見る
2. つぎに `script_exports` で export を確認する
3. `scene_bindings` で scene との結びつきを見る
4. `scene_audit` で問題の一覧を取る
5. 必要なら node や reference を掘る
