# 도구 도메인 인덱스

이 문서는 도구 도메인 디렉터리와 대표 역할을 빠르게 찾기 위한 인덱스입니다.

## 요약

- `tools/tool_registry.gd`가 등록 사실 소스입니다.
- 각 도메인은 보통 `executor.gd`를 가집니다.
- `system/`은 내부 구현이 가장 많습니다.

## 대표 도메인

- `system/`
- `scene/`
- `script/`
- `project/`
- `resource/`
- `editor/`
- `debug/`
- `user/`

## 유지 포인트

- 새 도메인을 추가하면 registry와 문서를 같이 갱신합니다.
- 도구 이름을 바꿀 때는 client-facing 문서와 preview 문구도 함께 바꿉니다.
