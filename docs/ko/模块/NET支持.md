# NET 지원

이 문서는 C# 정적 분석의 범위와 한계를 설명합니다.

## 지원 범위

- Roslyn 기반 구문 분석
- 클래스, 기반 클래스, 메서드, 열거형, export 멤버 확인
- 장면 바인딩과 export 분석 보조

## 지원하지 않는 것

- 프로젝트 전체 semantic compile 분석
- 외부 Roslyn 설치 요구
- 불필요한 중복 진입점

## 원칙

- syntax-first를 유지합니다.
- 가능한 한 프로젝트 내부에서만 해결합니다.
- 분석 결과는 도구와 UI가 바로 쓸 수 있는 형태로 유지합니다.
