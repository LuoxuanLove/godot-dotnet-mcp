# 스크립트와 장면 분석

이 문서는 `script_*`, `scene_bindings`, `scene_audit` 계열 분석 도구가 어떤 문제를 찾는지 설명합니다.

## 범위

- 장면 구조
- 노드와 스크립트 바인딩
- export 멤버와 리소스 참조
- C# 바인딩과 custom Resource 검사

## 분석 순서

1. 구조를 읽습니다.
2. 바인딩과 참조를 확인합니다.
3. 필요한 경우 patch나 audit를 수행합니다.

## 주의점

- `dotnet build`가 성공해도 로드 위험은 남을 수 있습니다.
- 장면과 스크립트 문제는 구조와 참조를 함께 봐야 합니다.
