# 도구 시스템

이 문서는 공개 도구가 어떤 분류와 호출 규칙으로 유지되는지 설명합니다.

## 핵심 구조

- 도구는 domain, category, tool 계층으로 정리됩니다.
- 상위 도구는 내부 atomic tool chain을 감춥니다.
- 공개 표면은 `system_*` 중심으로 유지합니다.

## 호출 규칙

- 입력과 출력 구조는 가능한 한 일정해야 합니다.
- 도구 설명은 클라이언트가 바로 읽을 수 있어야 합니다.
- category 이름은 쉽게 바꾸지 않습니다.

## 현재 태도

- 중복 진입점을 늘리지 않습니다.
- 이미 있는 도구를 더 명확하게 만듭니다.
- 도구 트리와 MCP 목록은 같은 사실 소스를 봅니다.
