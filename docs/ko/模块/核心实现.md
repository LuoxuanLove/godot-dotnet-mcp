# 핵심 구현

이 문서는 플러그인의 핵심 서비스와 공유 모듈이 어떻게 연결되는지 정리합니다.

## 범위

- `localization/`
- `plugin/config/`
- `plugin/runtime/`
- `custom_tools/`
- 공통 helper와 manifest 계층

## 역할

- 설정과 profile 저장
- 런타임 상태와 서버 제어
- 사용자 도구 발견과 유지보수
- 도구 메타데이터와 표시 모델

## 유지 원칙

- 공통 로직은 가능한 한 서비스 계층에 둡니다.
- UI는 가능한 한 얇게 유지합니다.
- 새 기능은 먼저 기존 계층에 맞는지 보고, 정말 필요할 때만 새 계층을 만듭니다.
