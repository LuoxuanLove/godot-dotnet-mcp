# 사용자 확장

이 문서는 `custom_tools/`에 들어가는 User 도구의 규칙과 운영 방식을 설명합니다.

## 핵심 규칙

- User 도구는 `user_*` 접두사를 사용합니다.
- 플러그인 내부 내장 도구와 섞지 않습니다.
- 발견, 스캐폴드, 감사, 복원 흐름이 나뉘어 있습니다.

## 운영 흐름

1. 도구를 발견합니다.
2. 필요하면 스캐폴드를 만듭니다.
3. 승인 후 생성하거나 갱신합니다.
4. 감사 기록을 확인합니다.

## 주의점

- 삭제 전 백업 디렉터리를 존중합니다.
- 런타임 재로딩 뒤에도 상태가 일관되어야 합니다.
