# 서비스와 라우팅

이 문서는 HTTP, JSON-RPC, tools API, editor lifecycle API가 어떻게 같은 서비스 계층 안에서 흘러가는지 설명합니다.

## 라우팅 계층

- `mcp_http_request_router.gd`가 path를 나눕니다.
- `mcp_json_rpc_router.gd`가 method를 나눕니다.
- `mcp_editor_lifecycle_endpoint.gd`가 editor lifecycle 요청을 처리합니다.
- `mcp_tools_api_service.gd`가 `/api/tools` 스냅샷을 만듭니다.

## 응답 규칙

- 모든 응답은 일관된 구조를 따라야 합니다.
- 오류는 가능한 한 구조화된 필드로 전달합니다.
- CORS, JSON 정리, protocol facts는 전담 서비스가 처리합니다.

## 도구 목록

- 공개 도구는 `tools/list`와 `tools/call`을 통해 접근합니다.
- 내부 atomic tool은 공개 표면으로 직접 노출하지 않습니다.
- tool manifest와 registry는 같은 사실 소스를 기준으로 유지합니다.
