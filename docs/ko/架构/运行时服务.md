# 런타임 서비스

이 문서는 `plugin/runtime/*`와 연결된 서버, 라우터, 컨트롤러, 런타임 브리지, 도구 로더의 역할을 정리합니다.

## 핵심 흐름

1. HTTP나 JSON-RPC 요청이 들어옵니다.
2. 라우터가 경로와 method를 분배합니다.
3. `MCPToolLoader`가 도구 실행을 맡습니다.
4. 런타임 브리지는 메인 프로젝트와의 이벤트 흐름을 유지합니다.
5. 각 서비스는 결과 구조를 통일해서 돌려줍니다.

## 주요 컴포넌트

- `mcp_http_server.gd`: 내장 서버 본체
- `mcp_http_request_router.gd`: HTTP path 분배
- `mcp_json_rpc_router.gd`: JSON-RPC method 분배
- `mcp_tool_rpc_router.gd`: tools/list, tools/call 정리
- `server_runtime_controller.gd`: 서버 생명주기 제어
- `tool_loader.gd`: 도구 로딩과 hot reload
- `mcp_runtime_bridge.gd`: 메인 프로젝트 런타임 이벤트 통로
- `runtime_control_service.gd`: 런타임 제어 조정

## 설계 원칙

- 상태와 요청 처리 책임을 섞지 않습니다.
- 장기 캐시는 서비스 단위로 유지합니다.
- 실패 정보는 가능한 한 구조화된 payload로 돌려줍니다.
- 브리지와 라우터는 서로 얽지 않고, 각자 맡은 경계를 유지합니다.
