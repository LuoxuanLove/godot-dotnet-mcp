# 생명주기와 조립

이 문서는 `plugin.gd`가 어떻게 Dock, 서비스, 설정, 브리지를 조립하고 재시작을 조정하는지 설명합니다.

## 진입 흐름

- `_enter_tree()`에서 상태를 읽고, 서비스와 Dock을 준비합니다.
- Autoload와 debugger bridge를 등록합니다.
- `mcp_dock.tscn`을 인스턴스화하고 신호를 연결합니다.
- 필요하면 자동 시작을 수행합니다.

## 재시작과 복원

- 완전 재시작은 독립 coordinator가 관리합니다.
- Dock의 탭과 포커스 상태는 재시작 뒤에도 복원할 수 있습니다.
- 설정과 profile은 저장 계층을 통해 다시 읽습니다.

## 책임 분리

- `plugin.gd`는 얇은 조립 계층입니다.
- 실제 서버 생명주기, 도구 카탈로그, 설정 저장, UI model 생성은 서비스 객체가 맡습니다.
- UI 스크립트는 서비스 내부 상태를 직접 만지지 않습니다.
