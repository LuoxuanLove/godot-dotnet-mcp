# 설정과 UI

이 문서는 Dock 탭의 책임, 설정 영속화, 설정 생성, 그리고 UI 배율 정책을 정리합니다.

## Dock 탭 역할

- `Home`은 서버 상태, 진단, 시작과 중지, 재시작을 담당합니다.
- `Tools`는 도구 노출 범위와 내부 계층을 관리합니다.
- `Config`는 클라이언트별 연결 설정을 보여주고 기록합니다.

## 설정 흐름

설정은 `SettingsStore`와 관련 presenter, serializer, transaction, launcher adapter가 나눠 맡습니다.

- UI는 값의 표시와 사용자 선택만 다룹니다.
- 실제 파일 쓰기와 읽기, 백업과 복구는 서비스 계층이 처리합니다.
- 파일 형식이나 경로 규칙이 바뀌면 문서와 테스트를 함께 갱신합니다.

## UI 배율 정책

- 유일한 배율 원천은 `EditorInterface.get_editor_scale()`입니다.
- 스크립트는 최소 높이, 트리 너비, 그림자 크기 같은 제약만 조정합니다.
- 일반 간격과 마진은 가능한 한 `.tscn`에서 조정합니다.

## 표시 원칙

- 텍스트는 Godot 자동 번역에 의존하지 않습니다.
- 각 탭은 model 기반으로 다시 그릴 수 있어야 합니다.
- 탭 스크립트는 표시와 상호작용만 맡고, 서버 생명주기를 직접 관리하지 않습니다.
