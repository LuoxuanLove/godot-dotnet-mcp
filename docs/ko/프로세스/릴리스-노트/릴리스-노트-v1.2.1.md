## 🧩 Godot .NET MCP v1.2.1: Editor Settings Reach

이 version line은 Agent가 editor configuration surface에 더 쉽게 직접 접근하도록 하는 변경으로 시작합니다. 정식 릴리스 전 `v1.2.0` 이후의 실제 user-visible change를 기준으로 이 note를 계속 채웁니다.

### ✨ Project Settings Control

`system_editor_control`은 이제 Project Settings를 열고 Plugins tab을 포함한 요청 tab을 활성화할 수 있습니다. coordinate-based menu automation에 덜 의존해도 됩니다.

### 🔧 Fixes Reserved

### ✅ Compatibility and Upgrade Notes

새 editor UI action은 기존 `system_editor_control` surface를 확장하며 plugin version은 `1.2.1` development line을 유지합니다.
