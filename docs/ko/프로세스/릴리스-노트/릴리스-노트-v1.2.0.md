## 🧩 Godot .NET MCP v1.2.0: 지역화 문서 트리와 i18n 검증

이 릴리스는 문서 품질과 더 안전한 플러그인 maintenance에 초점을 맞춥니다. 지역화된 문서 트리를 현재 플러그인 레이아웃에 더 가깝게 맞추고, 각 로케일 트리가 구조적으로 정렬되도록 검증을 강화했으며, lifecycle reload 전에 update-sync refresh 동작을 개선했습니다.

### ✨ 주요 내용

- 로케일 파일 일치, Markdown 링크 대상, 로케일 간 링크 섞임을 확인하는 docs i18n 검증을 추가했습니다.
- 현재 플러그인 UI, 도구, 바인딩 참조에 맞춰 지역화 문서 트리를 정렬했습니다.

### 🔧 수정 사항

- 서비스 라우팅, .NET 지원, UI 흐름, 도구 도메인 색인에 관한 영어와 일본어 문서 사실을 바로잡았습니다.
- 플러그인 update sync가 파일을 쓴 뒤 plugin lifecycle reload를 예약하기 전에 Godot editor file system을 refresh하도록 했습니다.
- 깨졌거나 오래된 지역화용 자리표시자를 현재 사용자 대상 내용으로 바꿨습니다.
- 일본어 README의 잘못된 스크린샷 참조를 제거했습니다.

### ✅ 호환성 및 업그레이드 안내

- Update sync는 lifecycle reload 단계 전에 editor가 plugin file을 다시 scan하도록 요청합니다.
- 파일 레이아웃이나 tool schema migration은 필요하지 않습니다.
- 기존 설치에는 마이그레이션이 필요하지 않습니다.
