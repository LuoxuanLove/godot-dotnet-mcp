## 🧩 Godot .NET MCP v1.2.0: 지역화 문서 트리와 i18n 검증

이 릴리스는 문서 품질에 초점을 맞춥니다. 지역화된 문서 트리를 바로 사용할 수 있는 사용자 참고 자료로 완성하고, 각 로케일 트리가 구조적으로 맞고 스스로 완결되도록 검증을 강화했습니다.

- 영어, 간체 중국어, 일본어, 한국어의 완전한 지역화 문서 트리를 추가했습니다.
- 한국어 문서 세트를 확장해 대상 페이지도 짧은 요약이 아니라 완전한 번역으로 읽을 수 있게 했습니다.
- 로케일 파일 일치, Markdown 링크 대상, 로케일 간 링크 섞임을 확인하는 docs i18n 검증을 추가했습니다.

- 서비스 라우팅, .NET 지원, UI 흐름, 도구 도메인 색인에 관한 영어와 일본어 문서 사실을 바로잡았습니다.
