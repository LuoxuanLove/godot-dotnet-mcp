### ✨ Protocol-First MCP Surface

v1.4 line은 default MCP surface를 2025-11-25 target으로 옮깁니다. passive context, status, logs, catalog discovery는 Resources에 위치하고, workflow orientation은 Prompts에 남으며, Tools는 actions 또는 computed workflow results에 집중합니다. legacy discovery calls는 first-class public tools가 아니라 명확한 replacement guidance를 반환합니다.

### 🌊 Streamable HTTP and Stdio

default endpoint는 `http://127.0.0.1:3000/mcp` 그대로지만 semantics는 Streamable HTTP에 맞췄습니다. protocol/session headers, JSON/SSE `Accept` negotiation, Origin/CORS checks, GET SSE streams, resumable event history, finite POST SSE responses, heartbeat events, queued server-to-client delivery, `DELETE /mcp` session termination을 포함합니다. Stdio는 newline-delimited JSON-RPC를 default로 사용하고 legacy `Content-Length` framing은 explicit compatibility mode로만 유지합니다.

### 🧭 Resource and Prompt UI

Dock은 Resources와 Prompts를 first-class tabs로 표시합니다. protocol catalog counts, copyable IDs, resource previews, prompt argument inputs, generated prompt previews, bounded icon rendering을 포함합니다. Tools tab도 shared catalog metadata를 사용해 titles, icons, annotations, input schemas, output schemas, previews, search, schema copy actions를 표시합니다.

### 🧠 C# Semantic Runtime

Asset Library 또는 prepared addon install 후에도 C# semantic tooling은 isolated Roslyn runtime bundle을 통해 사용할 수 있습니다. shipped addon은 Roslyn 및 bridge source files를 host project compile surface에서 제외하면서 semantic read / patch workflows를 유지합니다.

### ✅ Compatibility and Validation

이 line은 retired discovery tools의 compatibility guidance를 유지하고 HTTP/stdio JSON-RPC behavior를 harden하며 public tool removals, root monolith closure, catalog facts, optional capabilities, changelog structure, Roslyn runtime bundle shape, clean install validation guardrails를 추가합니다.
