# 테스트 개요

이 문서는 현재 테스트 체계의 전체 구조를 간단히 설명합니다.

## 구성

- 플러그인 headless harness
- contract test fixture
- smoke와 CI 검증
- 런타임, 장면, 스크립트, 도구 검증

## 기본 원칙

- 먼저 구조를 검증하고, 그다음 동작을 검증합니다.
- 검증은 가능한 한 실제 플러그인 경로를 탑니다.
- CI는 빠른 체크와 무거운 harness를 분리합니다.
