# 플러그인 Headless 테스트

이 문서는 Godot headless harness와 fixture의 역할을 설명합니다.

## 목표

- 플러그인 진입점이 정상적으로 뜨는지 확인합니다.
- 도구 등록과 서비스 라우팅이 깨지지 않는지 확인합니다.
- 런타임 오류와 파싱 오류가 성공 종료를 가리지 않는지 확인합니다.

## 현재 초점

- Roslyn 지원 경로
- 도구 목록과 도구 호출 경로
- 설정과 로드 상태
- 재시작과 재로딩 경로

## 주의점

- headless 검증은 UI 픽셀 정밀도보다 동작과 상태를 우선합니다.
- fixture와 본체가 다르면 검증 결과도 달라질 수 있으므로, 둘을 함께 갱신합니다.
