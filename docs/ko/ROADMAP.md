# 로드맵

이 문서는 Godot .NET MCP가 앞으로 다루려는 방향을 정리합니다. 문서와 구현이 어긋나면 구현 쪽을 우선합니다.

## 현재 중심 축

- 편집기 안에서 동작하는 MCP 서비스
- Godot 편집기 상태, 장면, 스크립트, 런타임, 진단의 안정적 노출
- Tools 페이지와 Config 페이지의 지속적인 개선
- Roslyn 기반 C# 지원과 GDScript 보조 분석
- headless harness와 CI 방어선의 안정화

## 앞으로의 정리 방향

1. 상위 도구 계층의 일관성 강화
2. UI와 문서의 현지화 품질 유지
3. 실행, 진단, 스크린샷, 입력 흐름의 안정성 보강
4. 테스트와 배포 절차의 예측 가능성 유지

## 메모

- 이 문서는 실행 계획이 아니라 참고용 방향표입니다.
- 릴리스 직전에는 항상 최신 changelog, release note, 검증 결과를 우선합니다.
