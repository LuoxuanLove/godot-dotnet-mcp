## 유지 규칙

- 각 언어 디렉터리는 완전하고 자기 완결적이어야 합니다.
- 한 언어 디렉터리에서 다른 언어 디렉터리로 링크하지 않습니다.
- 폴더 이름과 파일 이름은 해당 언어로 표기합니다.
- 공개 문서에 자리표시자 문구를 남기지 않습니다.
- 공개 문서 구조가 바뀌면 이 페이지도 갱신합니다.
